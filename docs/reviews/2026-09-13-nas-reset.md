# Local NAS reset and exact-image uniqueness

The local catalog was reset at the owner's request, preserving login,
configuration, watermarks and the existing storage profile. Working originals,
derivatives, local Ferraraphoto delivery files and Settings sample sources now
reside under `/Volumes/Public/proofgen-dev`. The pristine
`/Volumes/Public/_Backups/sample_show_photos` library was read only.

The old image trees were copied to the NAS reset backup, checked with a full
rsync checksum comparison, and then removed from local storage. A compact,
private SQLite snapshot remains in ignored local storage. See
[the dataset notes](../datasets/README.md) for paths and the 24-file manifest.

## Implementation and review

Pi's DeepSeek Flash worker implemented the bounded source-only hash lane.
It received source, tests and instructions, with no environment files,
credentials, database or photographs. Parent review added missing-original
pre-insert hashing, a direct-import overwrite guard, and in-place photo moves
and class renames so the unique constraint doesn't break those operations.

- Global uniqueness on non-null `photos.sha1`; existing duplicates make the
  migration stop with a diagnostic, without deleting or merging records.
- Normal imports and originals discovery hash before inserting records.
- Same-class identical bytes reuse the existing record/proof number; a missing
  original can be restored from verified incoming bytes.
- Cross-class identical bytes create a review issue linked to the owner.
  Assigning another proof number cannot bypass content uniqueness.
- Replacement checks the incoming hash and ownership before removing the old row.
- Settings sample path is configurable with `SAMPLE_IMAGES_PATH`.

The live run also reproduced an rsync discrepancy: Herd selected Apple's
openrsync, which transferred files but supplied no matching completion entries.
Upload timestamps remained empty. `RsyncRunner` now selects Homebrew rsync
explicitly (Apple Silicon or Intel), supports `RSYNC_BINARY`, and provides an
installation diagnostic if no supported installation is found. Browser-started
workers were restarted; retrying the deliveries set all upload timestamps.
